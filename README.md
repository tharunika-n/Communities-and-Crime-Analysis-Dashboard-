# 🚨 Community Crime Intelligence Dashboard

## 📌 Project Overview

The **Community Crime Intelligence Dashboard** is a data analytics and visualization project based on the **Communities and Crime Unnormalized Dataset**.

The project analyzes crime patterns and their relationship with socioeconomic and demographic factors across different communities and states.

The complete workflow was performed using **Excel for data cleaning and preparation** and **Power BI for data modelling, DAX calculations, analysis, and dashboard visualization**.

---

## 🎯 Project Objectives

- Clean and prepare the raw Communities and Crime dataset.
- Handle missing and inconsistent data.
- Remove unnecessary and highly incomplete columns.
- Transform the dataset into analytical tables.
- Build relationships between fact and dimension tables.
- Create meaningful DAX measures.
- Analyze crime and socioeconomic patterns.
- Develop an interactive and visually appealing Power BI dashboard.
- Generate descriptive, diagnostic, predictive, and prescriptive insights.

---

## 📂 Dataset

### Communities and Crime Unnormalized Dataset

The dataset contains information about communities, demographic characteristics, socioeconomic conditions, law enforcement factors, and different types of crime.

### Raw Dataset

- **Rows:** 2,215
- **Columns:** 147
- Contains socioeconomic, demographic, population, law-enforcement, and crime-related variables.
- Contains missing values in several attributes.

### Major Categories

- Community information
- Population characteristics
- Poverty
- Unemployment
- Housing
- Education
- Demographics
- Law enforcement
- Violent crime
- Property crime
- Murders
- Robberies
- Assaults
- Burglaries
- Auto theft
- Arson
